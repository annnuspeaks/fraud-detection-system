# Contributing

Thank you for your interest in contributing to the Fraud Detection System.

Whether you're fixing bugs, improving documentation, suggesting new features, or enhancing the machine learning pipeline, your contributions are always welcome.

---

## Ways to Contribute

You can contribute by:

- Reporting bugs
- Suggesting new features
- Improving documentation
- Optimizing frontend or backend code
- Enhancing the ML pipeline
- Improving UI/UX
- Writing tests

---

## Development Setup

Clone the repository:

```bash
git clone https://github.com/annnuspeaks/fraud-detection-system.git
```

Install dependencies for both frontend and backend.

Start the backend server.

Start the frontend development server.

---

## Coding Standards

- Write clean and readable code.
- Follow existing project structure.
- Keep functions modular.
- Add comments only where necessary.
- Test your changes before submitting.

---

## Commit Messages

Use meaningful commit messages.

Example:

```text
feat: add batch prediction endpoint

fix: resolve CSV upload validation

docs: update README deployment guide
```

---

## Pull Requests

Before creating a Pull Request:

- Ensure the project builds successfully.
- Verify that existing functionality is not broken.
- Update documentation if necessary.
- Keep Pull Requests focused on a single change.

---

## Bug Reports & Feature Requests

If you find a bug or have a feature request, please open a GitHub Issue with:

- Clear description
- Steps to reproduce
- Expected behavior
- Screenshots (if applicable)

---

## Code of Conduct

Please be respectful and constructive in all interactions.

This project welcomes contributions from everyone.

---

## Thank You

Thank you for helping improve the Fraud Detection System.

Your contributions make this project better for everyone.
